# Seedance 2.0 통합 프롬프팅

기존 seedance-2-prompting의 소재 바인딩·5블록 구조·타임라인·연장과 seedance-clean의 촬영·연기·공간 연출을 통합한다. 상충하는 이전 규칙 대신 이 문서를 따른다.

## 워크플로우와 출력

목적, 길이, 화면비, 제공 소재, 컷 방식을 대화에서 파악한다. 결과를 크게 바꿀 누락만 질문하고 사소한 선택은 합리적으로 정한다. 첫 화면, 행동 변화, 마지막 상태를 설계하고 복사 가능한 독립 프롬프트 하나를 코드 블록으로 출력한다. 여러 생성 클립을 요청하면 클립별 독립 코드 블록을 제공한다.

요청 언어를 따르고 지정이 없으면 대화 언어로 작성한다. 영문 전용으로 제한하지 않는다. 대사 원문과 사용자 태그는 보존한다. 해설은 필요한 경우에만 블록 밖에 짧게 쓰고, 프롬프트만 요청하면 생략한다.

## 소재 바인딩

- 사용자가 지정한 태그가 있으면 그대로 사용한다. 없으면 실제 업로드 순서로 @image1, @video1, @audio1을 사용한다. 없는 소재를 만들어 참조하지 않는다.
- 모든 제공 소재의 역할을 정하고, 사용하지 않을 소재는 제외한다고 설명한다. 화면에 없는 대상의 태그를 해당 컷에 넣지 않는다.
- 이미지는 외형·의상·제품·공간·첫/마지막 프레임, 비디오는 동작·안무·카메라·전환·리듬, 오디오는 음색·BGM·효과음의 역할을 구분한다.
- 참조 이미지가 외형을 정하고 텍스트가 행동을 정한다. 외모 설명은 최소화하되 중요한 로고·색·소품은 글로 명시한다.
- 예: '@image1의 인물 외형과 의상을 유지한다. 동작은 @video1, 카메라 궤적은 @video2를 참조한다.'
- '완전히 참조'는 복제 범위가 명확할 때만 사용한다. 카메라 참조에서 원치 않는 외모까지 가져오지 않는다.

## 기본 5블록

1. 소재 바인딩: 실제 소재와 각각의 역할. 소재가 없으면 생략한다.
2. 피사체 + 공간 + 첫 화면: 인물 위치·시선·방향·손·소품, 전경·중경·배경, 광원과 이동 경로.
3. 동작 + 시간 + 컷 방식: 관찰 가능한 행동, 시작과 끝 상태, 필요한 타임라인과 컷 지점.
4. 카메라 + 오디오: 샷 크기, 높이·거리·이동·초점, 대사·현장음·음악.
5. 스타일 + 유지 조건: 질감·색감·형식과 외형·의상·소품·공간의 연속성.

조명·연기 지시는 해당 내용 가까이에 배치하고 일반적인 스타일 문구를 앞에 길게 쌓지 않는다. 블록 번호나 제목은 출력에 필수가 아니다.

## 장면과 컷 제어

- 감정을 행동으로 쓴다. '긴장한다' 대신 '잔을 쥔 손가락이 굳고 숨이 짧아지며 시선은 상대에게 머문다'.
- 카메라 움직임과 피사체 움직임을 구분한다. 한 구간에 고정과 오빗처럼 충돌하는 지시를 겹치지 않는다.
- 원테이크는 '하나의 연속 촬영으로 끝까지 이어진다'를 명시한다. 행동 비트의 변화는 컷을 뜻하지 않는다.
- 순차 멀티샷은 CUT 1, CUT 2로, 정확한 타이밍이 중요하면 '0–3초', '3초 HARD CUT'으로 지정한다. 지정 지점에서만 컷하도록 명시한다.
- 자유로운 B-roll은 필요하지 않은 컷 고정을 피한다. 페이드·크로스페이드는 의도한 경우만 사용한다.
- 긴 장면이나 복잡한 행동은 약 3초 단위 비트를 출발점으로 삼되 강제하지 않는다. 타임라인은 0초부터 종료까지 빈틈·중복 없이 이어지고 실행 가능한 핵심 행동을 배치한다.
- 매 생성은 독립적이다. '앞 장면처럼'만 쓰지 말고 필요한 현재 상태를 다시 적는다. 컷 전후 시선·화면 진행 방향·의상·광원·소품 상태를 유지한다.
- 원하는 상태를 긍정형으로 쓰는 것을 우선하되 사용자 요청인 NO BGM, 추가 컷 금지 등 필요한 명시적 제약은 보존한다.

## 세부 영화 연출

복잡한 장면은 필요한 항목만 다음 순서로 펼친다. CAMERA를 반드시 3번째에 두라는 별도 규칙은 적용하지 않는다.

SCENE CONTEXT → ACTIVE REFERENCES → LOCATION MAP → FIRST FRAME / BLOCKING → FORMAT MODE → OPTICS → CAMERA → ACTION → PERFORMANCE → PHYSICS → LIGHTING → COLOR GRADE → WARDROBE → AUDIO → STYLE / OUTPUT SETTINGS → CONTINUITY LOCKS

- 블로킹: 인물 간 거리, 시선, 손 위치, 이동 경로를 명시한다. 좌우는 화면 기준이다.
- 연기: 미세한 정지, 턱·손가락의 긴장, 호흡과 시선으로 감정 변화를 만든다. 반응을 읽을 시간을 둔다.
- 물리: 무게·관성·접촉, 피부의 빗물, 바람과 옷감 같은 상호작용을 구체화한다.
- 조명·색: 광원·방향·명암 대비를 정하고 필요하면 일정한 색온도를 적는다. 색은 재질과 빛에 연결한다.
- 카메라: 푸시 인·풀 백·팬·틸트·트래킹·오빗·크레인·돌리 줌·휩 팬 중 의도에 맞는 움직임을 선택하고 움직일 이유를 정한다.
- 광학: ECU/CU/MCU/MS/WS/EWS 등 샷 크기와 광각·표준·망원 성격을 지정한다. 초점거리·FOV는 필요할 때만 사용한다. 센서와 화각 축에 따라 환산이 달라지므로 고정 표를 강제하지 않는다.
- 속도 km/h, 안개 %, 특정 FOV, 휩 팬 최소 시간은 필수가 아니다. 의미 있는 경우에만 수치를 쓴다.
- 장비·감독 이름 대신 시각적 특성을 기본으로 설명하되 사용자의 명시적 참조는 보존한다.
- 형식·해상도·fps는 해당 서비스에서 설정 가능할 때 안내한다. 프롬프트에 '8K'를 쓴다고 실제 8K 출력이 보장되는 것은 아니다.

### 선택적 광학 패턴

먼 관찰 시점은 흐린 전경 가림 + 카메라와 인물 사이 대기층 + 먼 망원 시점을 조합한다. 스포츠 중계는 멀리 고정한 망원 시점의 작은 추적 조정, 디테일 온 와이드는 작은 물체에 가까운 낮은 광각, 친밀한 광각은 중앙 얼굴과 읽히는 주변 공간을 사용한다.
극단적 화각의 멀티샷은 구간별 광학 성격과 동일 공간 구조·외형·의상·소품을 재확인한다. 특별한 속도 램프 의도가 없으면 한 샷의 재생 속도를 유지하고 실시간·슬로모션 전환은 컷에서 한다.

## 오디오

대사, 호흡·발자국·옷감·환경음, BGM의 역할을 구분한다. 음악이 필요하지 않은 장면에 임의로 BGM·충격음·전환음을 추가하지 않는다. 사용자의 무음 또는 NO BGM 요청을 우선한다.

## 연장과 다단 생성

서비스와 모드가 연장을 지원할 때 사용한다. 지원하지 않으면 다음 클립 생성과 편집 연결을 제안한다. 원본 마지막 프레임의 인물 위치·시선·손·소품·젖음·파손 상태·카메라·광원을 다시 적는다. 생성 길이는 새로 추가할 분량에 맞추고 전체 길이와 클립 내부 시간을 구분한다. 긴 영상은 클립 간 핸드오프 상태를 설계하며 각 클립을 독립 프롬프트로 작성한다. 역방향 연장과 마지막 프레임 지정도 해당 모드에서 지원할 때만 제안한다.

## 서비스 사양

파일 개수·용량·형식·생성 길이·해상도·실존 인물 참조 허용 여부는 서비스와 모드별로 다르다. 실행에 필요하면 현재 화면이나 공식 안내로 확인하고 미확인 제한을 확정하지 않는다. 프롬프트 초안만 작성할 때 불필요한 사양 조사로 지연하지 않는다.

## 예시: 이미지 참조 1장, 10초 원테이크

```text
@image1의 인물 외형과 의상을 유지한다.
밤의 비 내리는 골목. 인물은 화면 중앙 중경에서 고개를 숙이고 서 있다. 전경의 젖은 아스팔트에 가로등이 반사되고 뒤쪽 골목은 어둠으로 이어진다. 가로등은 왼쪽 뒤에서 머리카락과 어깨 가장자리를 비춘다.
0–4초: 두 걸음 앞으로 걷는다. 젖은 머리카락이 뺨에 붙고 빗물이 소매를 따라 흐른다.
4–7초: 걸음을 멈추고 시선을 천천히 위로 옮긴다. 턱에 힘이 들어가고 입술이 작게 떨린다.
7–10초: 오른손으로 뺨의 빗물을 닦은 뒤 손을 내린다.
눈높이 미디엄 샷에서 카메라가 일정하게 전진해 마지막에 클로즈업으로 도착한다. 하나의 연속 촬영으로 끝까지 이어진다.
빗소리, 젖은 바닥의 발소리, 짧은 호흡만 들린다. BGM 없음.
차가운 주변광과 따뜻한 가로등의 대비, 부드러운 하이라이트, 섬세한 필름 그레인. 외형·의상·광원 방향은 끝까지 유지한다.
```

## 최종 점검

실제 소재와 역할 / 첫 화면과 종료 상태 / 실행 가능한 행동량 / 빈틈 없는 타임라인 / 컷 방식의 일치 / 카메라와 인물 동작 구분 / 광원·의상·소품 연속성 / 필요한 음향만 지정 / 요청 언어·대사·태그 보존 / 미확인 사양이나 품질 보장 없음.
